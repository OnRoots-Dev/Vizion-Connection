# Viz Map Specification

Status: **Planned MVP.** This document’s formal product name is **Viz Map**. Mapbox GL JS is planned, not installed/current.

Viz Map discovers eligible Activities, Moments, Places, and people. At low zoom cluster markers; show counts/categories, then progressively disclose cards. Filter by sport, type, time, and approximate area. Do not place public markers for private content; support approximate/place-level location when exact coordinates are unsafe.

Future: route/course layers and Strava-like tracking. No Mapbox implementation in this phase.
