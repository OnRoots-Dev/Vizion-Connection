# Viz Map Specification

## Product name
Formal product name: **Viz Map**. `09_WORLD_MAP_SPEC.md` is retained for compatibility with the requested file name.

## Purpose
Show nearby or relevant sports activity, Moments, Places, and people. The map exists to make sports discovery spatial.

## Planned stack
Mapbox GL JS is Planned. Do not claim it is production-integrated merely because discovery/map-related pages exist.

## MVP behavior
- Pan/zoom
- Activity markers
- Moment markers
- Place markers
- relevant user markers
- clustering to prevent information overload
- marker → card → Activity/Moment/Profile flow

## Interaction
Map gestures should feel fast and spatial. Cards should not trap the user. Use progressive disclosure and preserve map context.

## Future
Route, course, and Strava-like Activity tracking are Future concepts.
