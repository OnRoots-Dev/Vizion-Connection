# Activity Skill

## Purpose
Activity is the core recurring action of Vizion Connection.

## Rules
- Treat Activity as a domain action, never a generic social post.
- Prefer place-aware data.
- Minimize input burden.
- Use presets and selection controls.
- Require type/date/time/place/visibility at the product level.
- Support optional title/description/media/tags/participants.
- Make Activity reusable as Moment context.
- Preserve current Journey implementation until migration is approved.

## Avoid
Long forms, unnecessary metadata, invented schema, duplicate Journey/Activity models, or social-post semantics.
