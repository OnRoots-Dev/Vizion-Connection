# Taste UI Skill

## Purpose
Create Vizion UI that feels modern, premium, minimal, dynamic, social, spatial, and sports-oriented.

## Rules
- Read `design-system/MASTER.md` and `lib/design/tokens.ts` first.
- Reuse existing components and tokens.
- Never hard-code colors, arbitrary spacing, or new motion recipes when an approved token exists.
- Prioritize hierarchy and interaction over decoration.
- Use motion to explain state, not to add noise.
- Cheer/Connection/Moment/Map interactions may receive stronger feedback, but always provide reduced-motion behavior.

## References
Nike, Apple, Instagram, TikTok, BeReal, Strava and modern map apps are inspiration only. Never copy brand identity or layout literally.

## Review checklist
Accessibility, 44px targets, focus states, mobile behavior, empty/loading/error states, token usage, and motion restraint.
