# Taste UI Skill

Build a Vizion-native UI: modern, premium, minimal, dynamic, social, spatial, and sports-oriented. Read `05_UI_DESIGN_SYSTEM.md` and `design-system/MASTER.md` first. Reuse tokens/primitives; never copy reference brands. Use subtle card transitions, gesture-aware sheets, map context preservation, gold Cheer reward, and reciprocal Connection feedback. Respect 44px targets, AA contrast, focus states, and reduced motion/transparency.
