# Viz Map Skill

## Purpose
Build spatial discovery around real sports activity.

## Rules
- Use Mapbox GL JS only when approved and configured.
- Map Activity, Moment, Place, and eligible users; never expose private objects.
- Cluster dense markers.
- Marker click should lead to a contextual card, then domain detail.
- Keep map state separate from domain authorization.
- Avoid loading every object into the client.
- Support mobile gestures and reduced-motion behavior.

## Future
Routes, courses, and tracking are Future, not MVP assumptions.
