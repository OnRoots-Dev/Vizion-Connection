# UI Reference

References are inspiration, not templates: Instagram, TikTok, X, BeReal, Strava, modern social applications, and modern map applications.

## Translate, do not copy
Extract interaction principles rather than visual identity. Vizion must preserve its own design tokens, information hierarchy, terminology, and sports/spatial context.

## Priority interactions
1. Cheer feedback: fast, tactile, celebratory but not noisy.
2. Connection: visually communicates relationship formation.
3. Moment: media-first evidence with contextual Activity link.
4. Map: smooth pan/zoom, contextual cards, clustering, progressive disclosure.
5. Cards: clear hierarchy, press/hover behavior, predictable transitions.

## Anti-patterns
Avoid generic social feed clones, excessive glassmorphism, infinite animation, emoji-as-icon, dense map labels, and interactions that require precision tapping.
