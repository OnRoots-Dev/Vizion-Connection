## 2026-09-07 Webhook完了時の副作用が失敗すると再送でも補修されない

- `app/api/webhooks/square/route.ts` の支払い完了処理は、`markBusinessOrderCompletedById` が「completed」を返すと
  `setUserSponsorPlanByEmail` / アカウント有効化 / `ad_slots` 加算を続けて実行する。
- しかし主処理が完了済みの状態で再送された場合（Squareのリトライ）は「already」で**早期リターン**し、
  sponsor_plan・activation・ad_slots の副作用は再実行されない。
- そのため主処理成功後に副作用だけが失敗した場合、決済は確定したのにプラン未反映・在庫未加算のまま放置され得る。
- 対応方針（キャンペーン後に対処）: 副作用を冪等ルート（例: 既存処理を成功を決めない順序で再実行、または失敗時に Webhook再送で再試行できる状態遷移）に変更する。
- **教訓**: 「入り口で冪等にする」だけでは、後続の副作用の失敗を救えない。完了＝すべての副作用が効いた状態、で判定する。
