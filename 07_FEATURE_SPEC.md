# Feature Specification

The product is organized around identity, activity, discovery, interaction, coordination, and business—not an undifferentiated feed.

| Domain | Current | MVP / Planned |
|---|---|---|
| Identity | Profiles, public portfolio, careers, journeys | Vizion ID normalization |
| Activity | Daily log/Journey adjacent behavior | canonical Activity |
| Publishing | Journey/news content | Moment linked to Activity |
| Discovery | profile/discovery routes | Viz Map spatial discovery |
| Interaction | Cheer, bond/follow-adjacent features, News comments | Moment comments and Connection |
| Coordination | Schedule/events | activity participation |
| Business | ads, slots, offers, sponsorships, Square | contextual discovery |
| Experimentation | VoiceLab/Open Lab posts | discoverable Open Lab |
