# UX Flow

## First impression

`LP → Register → onboarding → Viz Map or Dashboard`

Onboarding asks only enough to create a useful identity: role, sport/interests, location preference, and profile basics. Defer optional portfolio detail.

## Discovery

`Viz Map → Activity → Moment → owner → Vizion ID/Profile → Cheer, Comment, Connection`

Show visibility and place precision before entering an object. Do not expose private schedules or exact sensitive locations.

## Creation

`Create Activity → choose type/date/time/place/visibility → optional details → save → create or attach Moment → eligible Viz Map listing`

Use presets, remembered choices, date/time and place pickers. Never force a long social-post form.
