# UX Flow

## First impression
LP → Register → Verification → Onboarding → Viz Map / Dashboard.

## Discovery
Viz Map → Activity → Moment → Person → Vizion ID/Profile → Cheer / Comment / Connection.

## Creation
Activity creation → Place selection → optional Moment → visibility → publish → Map/Discovery exposure.

## Activity quick-create
Prefer role-aware presets, date/time picker, place picker, visibility control, and optional media. Avoid long forms.

## Profile conversion
Identity must be visible immediately. Portfolio, career, schedule, network, and detailed information are progressively disclosed.

## Social loop
Cheer should provide immediate feedback. Comment opens deeper conversation. Connection should require a meaningful relationship action rather than acting as a cosmetic Follow.

## Business flow
Business landing → plan/area selection → checkout → webhook completion → inventory update → Business identity/presence.

## Error and empty states
Every primary flow needs loading, empty, validation, permission denied, network/server failure, and success states. Never expose raw backend errors or PII.

## Responsive rule
Mobile is first-class for discovery and interaction; desktop should exploit spatial map and dashboard surfaces without changing the underlying domain model.
