# User Roles

| Role | Primary actions | Public identity |
|---|---|---|
| Athlete | Record practice, matches, events, moments and goals | sport, level, place, portfolio |
| Trainer | Offer sessions/coaching and share expertise | specialty, availability, track record |
| Crew | Attend, support, discover, join communities | interests and participation |
| Business | Publish relevant activity/moments; discover and support the ecosystem | organization, place/service, offer |

All four can own a Profile, Vizion ID, Activity, Moment, and visibility settings where the object allows it. Business permissions grant business surfaces, not blanket access to user data. Admin remains internal and requires explicit authorization.
