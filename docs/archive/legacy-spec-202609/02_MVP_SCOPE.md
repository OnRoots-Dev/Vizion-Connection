# MVP Scope

| Priority | Scope | Status |
|---|---|---|
| Must | Authentication, Profile, Vizion ID, Schedule, Cheer, existing Square checkout | Current; harden/reuse. |
| Must | Activity, Moment, Viz Map, Connection | Planned MVP; define canonical data/API before UI. |
| Should | Comments on Moments, Open Lab surfacing, Business discovery | News comments and limited VoiceLab/Business are Current; cross-product use is Planned. |
| Later | Skill taxonomy, Community foundation | Planned. |
| Future | Route/course tracking, advanced collaboration/community, automated matching | Future. |

MVP acceptance is a user can register, establish identity, create a low-friction activity with time/place/visibility, publish a related moment, discover it on Viz Map, and respond safely with Cheer, comment, or Connection.
